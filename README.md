# Кач

Личный трекер тренировок. PWA: React + Vite + Tailwind, данные в localStorage на устройстве.

Деплой: push в `main` → GitHub Actions → https://vasilev-gregory.github.io/ka4/

Локально: `npm i && npm run dev`

## Правила разработки

- Запущенная тренировка (`active` в состоянии) должна переживать любой деплой: пользователь может обновить приложение посреди тренировки.
- Схема данных меняется только совместимо: новые поля с дефолтами, перенос старых данных через `migrate()`. Ничего не удалять и не переименовывать без миграции.
- Состояние хранится в localStorage под ключом `gymapp-state-v1` (+ `-backup`). Ключ не менять.
- Добавляя упражнение, сразу добавлять его одностороннюю вариацию (одной рукой / одной ногой), если такая существует.
